  • 股票代码：0001.HK
  • 行业：综合集团
  • PE（TTM）：~19倍

投资亮点

  1. 全球多元化集团——港口、零售、基建、能源、电讯
  2. 资产出售释放价值（3UK合并、UKPN出售等）
  3. 净负债率极低（降至7%）
  4. 李嘉诚家族长期资本配置能力

核心风险

  1. ROE仅2-3%——13家中最低
  2. 综合折让严重（市场厌恶复杂集团）
  3. 3UK合并产生105亿港元一次性亏损
  4. 业务过于分散，难以形成合力
