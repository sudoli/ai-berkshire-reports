  • 行业：固网/移动通信

投资亮点

  1. 天翼云/AI数据中心增长强劲（AIDC收入345亿元）
  2. 75%高派息率，股息收益率可观
  3. 从传统运营商向"科技型企业"转型
  4. 低估值+稳定现金流

核心风险

  1. 传统通信业务增速见顶
  2. 云业务面临阿里云、华为云激烈竞争
  3. 5G大规模投资但ARPU提升有限
  4. ROE仅7%，资本回报率偏低
