投资亮点

  1. 收入增速强劲（18.8%），突破2000亿元
  2. 一体化供应链模式形成竞争壁垒
  3. 外部客户收入占比持续提升，去京东化
  4. AI/自动化降本增效空间大

核心风险

  1. 人力密集型企业，66万+员工，成本刚性
  2. 毛利率偏低（~9-10%），利润薄
  3. 与京东集团关联交易依赖
  4. 快递行业价格战风险
