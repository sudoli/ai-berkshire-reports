研究框架

本研究采用四维度并行分析框架：

01-商业模式分析 商业本质与护城河 垂直一体化模式、面料研发壁垒、客户粘性

03-行业竞争分析 竞争格局与产业链 多元思维模型、竞争对手、行业演变
04-风险管理层评估 风险与管理层 地缘政治、客户集中、接班人、企业文化
最终报告 综合评估 四维度汇总、综合评分、投资建议
