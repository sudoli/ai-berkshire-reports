核心定位

亚太区最大的房地产投资信托基金，以香港社区零售商场为核心，辅以中国内地、澳大利亚、新加坡及英国的零售、办公及物流资产。物业组合地理分布：香港74.4%、中国内地13.8%、海外11.8%。

研究框架

本研究采用四维度并行分析框架，从不同角度深入剖析领展的投资价值：

文件 分析维度 核心问题
01-商业模式分析 商业模式与护城河 这门生意的本质是什么？能否长期赚钱？
02-财务估值分析 财务健康与估值 当前价格是否提供足够的安全边际？
03-行业竞争分析 行业生态与竞争格局 长期结构性因素是顺风还是逆风？
04-风险管理层评估 风险与管理层 什么情况下论文会被证伪？管理层值得信任吗？
最终报告 综合研判 综合四维度的买入/观望/回避建议
