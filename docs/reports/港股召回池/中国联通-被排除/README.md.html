投资亮点

  1. 混改红利尚存，与BAT深度合作
  2. 5G专网/物联网/车联网高速增长
  3. 算力投资占比提升至35%+
  4. 估值在三大运营商中相对合理

核心风险

  1. ROE仅5.7%，三大运营商中最低
  2. 移动用户规模最小（3.4亿），规模劣势明显
  3. 营收增速几乎停滞（+0.7%）
  4. 核心利润偏薄，增长动力不足
