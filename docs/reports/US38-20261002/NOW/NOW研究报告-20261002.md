# ServiceNow（NOW）研究报告

**研究日及信息截止：2026-10-02。** 估值价格为2026-09-30常规交易收盘 **134.01美元**，Yahoo日线、StockAnalysis历史表同日close均与用户截图一致；两站底层行情供应链未独立核查，非10月2日实时价。最新核实财务为2026Q2，截止2026-06-30，2026-07-22公告、7月23日提交10-Q。

**拆股校验：公司实施1拆5，2025-12-17生效，12月18日开始拆后交易。** 2025-12-05官方公告与2026Q2财报脚注共同确认。因此134.01美元按拆后每股理解，不能直接套用拆股前EPS或约2亿股的旧股本。本报告模型、股数和所有价格均为拆后口径；2022年旧EPS不拿来直接比较。

以6月末10.33862亿普通股估算市值1,385.48亿美元，非当日实时股数市值。**核心判断：企业执行流程的护城河比聊天界面深，但SBC、AI成本与大型收购使“便宜的自由现金流倍数”具有误导性。**

## AI研究偏见自觉

信息丰富度A级，综合置信度中。最易忽略的是公司同时使用收入增长、非GAAP利润、调整FCF及并购贡献；把几种最有利的口径拼在一起，会产生不存在的经济利润。资料没有提供每种AI功能的独立单位成本、细分产品利润或完整价格折扣分布，不能用部署数量证明回报率。

## 第一步：生意本质与历史趋势

ServiceNow向大型机构出售流程执行与自动化平台，起点是IT服务管理，扩展至资产运营、员工服务、客户服务、安全及风险工作流。企业用它记录事件、安排任务、执行权限和审批、跟踪资产及服务等级。收入主要来自平台订阅及附加模块，服务收入较小且可能亏损，是交付与生态的配套，而非利润核心。

客户买的不只是工单页面，而是“在正确权限下把跨系统工作真正完成”。CMDB、流程配置、审计和长期集成提高转换成本；但实施复杂性、咨询费与合同成本同样可能促使客户寻找替代。

单位为十亿美元；简单FCF为OCF减固定资产购置，避免与公司调整FCF混用。

四年收入及净利润由SEC和Yahoo独立供应商时间序列核对。净利润不完全代表营业盈利：2023年尤其需要考虑税项而不是误读为下一年竞争突然恶化。2025年SBC占收入14.72%，扣SBC后的简单FCF仅26.21亿美元；不应把45.76亿美元都当成可分配给原股东的经济现金。

2026Q2总收入39.87亿美元、同比+24%，订阅38.77亿美元、同比+24.5%，专业服务及其他1.10亿美元。cRPO132亿美元、同比+21%，RPO290亿美元；这些是未履约收入可见度，不是净利润。公司表示AI年合同额超过10亿美元，但ACV与当期收入不同，新增定义、并购和合同期限也会影响比较。

当季GAAP营业利润1.62亿美元、营业率4%，调整后营业利润11.73亿美元、利润率29.5%。差额包括SBC、无形资产摊销、并购和遣散等；GAAP净利润2.98亿美元、EPS0.29美元，调整净利润9.30亿美元、EPS0.90美元。GAAP利润又受战略投资收益等影响，所以任何单一EPS乘四都不适合。

公司2026年订阅收入指引157.60—157.80亿美元，调整营业率31.5%、调整FCF率35%。Q2订阅部分受美国政府本地部署收入提前确认影响，将Q3收入前移；Q3订阅增长指引约20.5%，不能把Q2增长机械外推。

## 第二步：护城河与AI收费转型

| 护城河 | 评价与反证 |
|---|---|
| 工作流与权限转换成本 | 强：企业执行逻辑和资产上下文很难一次迁移；外部模型仍需受控执行工具 |
| 系统记录与治理 | 较强：CMDB与合规积累有价值；若数据质量差，AI无法凭空修复 |
| 生态与采购信誉 | 大客户和实施伙伴支持扩展，但不能把咨询生态视作不可突破壁垒 |
| 定价能力 | 用户、模块与AI新包装可扩展合同；客服/IT岗位自动化也会减少席位 |
| 网络效应与技术独占 | 跨客户网络效应弱，基础模型非独占；微软、Salesforce、Atlassian、BMC及自建均可争夺预算 |

2026年公司推动AI原生商业包装，将模型连接、治理和执行嵌入平台。投资要问两件事：客户是否愿意为机器完成的工作追加预算；推理、云托管和并购产品成本是否吞掉新增收入。公司Q2订阅非GAAP毛利率80.5%，低于上年83%，全年指引也反映更多超大规模云合作和AI使用。AI是需求来源，同时也是成本来源。

> 生意追问：即使前台被任何AI助手替换，后台执行规则是否仍须经过ServiceNow并付费？

## 第三步：管理层与资本配置

Bill McDermott团队扩大大客户合同、跨部门销售和AI产品；这些有收入及cRPO支持。另一方面，Moveworks、Veza、Armis等整合增加组织与资本风险。2026上半年现金并购净支出87.76亿美元、回购22.25亿美元；不是“低资本开支”就等于没有资本消耗。

**债务必须把短期部分算进去。** 6月末短债20.82亿美元、长债54.35亿美元，合计75.17亿美元。现金25.03亿美元＋短期证券21.61亿美元＝46.64亿美元，对应净有息债务28.53亿美元；再计长期可交易证券20.43亿美元，广义净债务仍为8.10亿美元。不能只用长债误判为净现金公司。战略股权投资不等于随时可用于偿债的现金。

Yahoo TotalDebt84.53亿美元包含经营租赁，较有息借款多9.36亿美元；财报租赁短期1.14亿＋长期8.22亿正好解释差额。公司明确回购主要目的包括抵消稀释；2026年提出2029年SBC/收入低于10%的目标，是未来承诺而非本期达成。本次未核实高管最新持股及薪酬投票，不能据职衔推导治理优良。

## 第四步：反面论证与监控

最强空头观点：平台会继续增长，但更多增长依赖并购、销售包装和AI成本投入；机器代替员工后，席位减少的速度可能快于按任务收费。原股东同时承担SBC和收购融资，经济现金增长低于调整FCF展示。公司不必失去行业地位，47倍正常所有者现金收益就可能压缩到30倍。

| 风险 | 主观判断 | 警戒指标 |
|---|---|---|
| AI重构席位收费 | 中等可能、高影响 | 大客户合同扩张不能覆盖席位下降；AI收入升、毛利降 |
| 并购整合与杠杆 | 发生中、影响高 | 商誉扩大而有机增长减弱、短债滚动依赖增强 |
| 收入时点与订单质量 | 明确需警惕 | 本地部署前移、cRPO持续弱于收入、合同期限延长 |
| 股权薪酬侵蚀 | 持续存在 | SBC比例不降、回购只能维持股数 |
| 安全/流程事故 | 低频高损失，无法量化概率 | 大规模权限错误或服务中断导致客户流失 |

模型失效研究线：连续两个季度剔除并购与汇率的cRPO增长低于15%，或订阅非GAAP毛利率持续低于78%，或扣SBC正常现金收益下修。不是触线自动卖出，而是停止原模型并重做估值。

## 第五步：估值与三年情景

不直接用公司35%的调整FCF率。2026上半年OCF22.57亿美元、资本开支2.55亿美元，简单FCF20.02亿美元；公司调整FCF22.99亿美元，加回并购等现金支出2.97亿美元。现金流表SBC11.99亿美元，营业利润调节中的SBC12.13亿美元含口径差异，不能任意挑更小者表达改善。

正常收益模型：研究假设2026总收入162亿美元，接近订阅指引加服务；162×35%＝56.70亿美元调整FCF，扣预计SBC24亿美元及至少3亿美元现金调整缓冲，除10.40亿稀释股约2.85577美元，向下取 **2.85美元/股**。这不是GAAP EPS、不是公司承诺，也未忽略SBC。半年已发生的现金调整意味着缓冲可能不足，属明确风险。现金利息已进入OCF，因此不再从每股现金估值重复扣全额净债务。

现价对应47.02倍正常所有者现金收益。已承担SBC经济成本，情景不再重复按同一奖励推算股数膨胀；未来有机每股增长若不达标直接下调。

| 情景 | 每股正常现金收益年增长 | 三年每股收益 | 退出倍数 | 三年价格/美元 | 相对134.01收益 |
|---|---:|---:|---:|---:|---:|
| 熊 | +10% | 3.79335 | 22倍 | 83.45 | -37.73% |
| 基准 | +18% | 4.68264 | 30倍 | 140.48 | +4.83% |
| 牛 | +24% | 5.43388 | 38倍 | 206.49 | +54.08% |

三年是约2029年的简化终值，股息、税费不计，期间留存现金不另行加总；倍数是研究假设，非历史分位结论。基准即使每股现金收益增长18%，现价的价格年化回报仅约1.58%；若要求10%年化且退出30倍，必须增长约27.78%，比基准高得多。

**今天的条件买带为92.37—105.54美元**：140.479236÷1.15³至÷1.10³，对应基准终值以15%—10%必要回报折现。不是140.48美元买入上限，也不是拆股前价格。软件质量可支持较高倍数，但“好公司”不足以证明现价有安全边际。

## 第六步：决策与行动

| 对象 | 建议 |
|---|---|
| 空仓者 | 134.01美元等待价格；92.37—105.54美元内仍须复核收购后现金流与债务 |
| 持仓者 | 观察有机cRPO、AI毛利与SBC；不因为拆后数字变小误认便宜 |
| 加仓 | 扣SBC现金收益兑现、并购整合可控、短债与总债务改善 |
| 减持/失效 | 高增长转为并购驱动、毛利持续低于假设、净债务上升或流程信任受损 |

六关检查：业务可理解；经济性强但SBC重；转换成本强；收购资本配置待验证；现价安全边际不通过；需要纪律等待而非追逐AI标签。镜子测试：“我买的是治理和执行的持续现金，不是拆股后的低数字，也不是把员工薪酬加回的表面FCF。”
